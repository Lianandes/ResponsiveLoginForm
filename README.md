# Responsive Login Form

Projeto desenvolvido para praticar a criação de formulários responsivos utilizando HTML e CSS através de uma interface moderna de login.

## 🚀 Objetivo

O objetivo deste projeto foi aprimorar conhecimentos em desenvolvimento front-end, responsividade e estilização de formulários utilizados em aplicações web.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Funcionalidades

- Formulário responsivo
- Interface moderna
- Campos estilizados
- Layout adaptável
- Design organizado

## 📚 Conceitos praticados

- Responsividade
- Estilização de formulários
- Flexbox
- Media Queries
- Estruturação de interface
